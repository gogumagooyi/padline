# Padline

Padline is a 4×4 rhythm game with a 30-second synthesized soundtrack. Press a glowing pad’s row and column keys together in time with the beat to score points and build a combo.

## Play locally

Download and extract the project, then open `index.html` in a browser. Select **Start game** and follow the count-in. The game runs entirely in the browser, including its synthesized audio and local personal-best score.

## Controls

| | First | Second | Third | Fourth |
| --- | --- | --- | --- | --- |
| Row, top to bottom | A | S | D | F |
| Column, left to right | J | K | L | ; |

For row 2, column 2, press **S** and **K** together. Either key can land first. The presses must overlap and begin within 120 milliseconds of each other. Release the keys and play a fresh pair for each note.

On a touchscreen, use two fingers to press one on-screen row key and one column key together.
